Stroke Risk Prediction and Care Planning

This web application uses a Logistic Regression model to estimate stroke risk from patient features, then uses a PDF-based Retrieval-Augmented Generation workflow to provide educational care planning guidance.

Start Prediction

What this app does

  • Predicts stroke risk category and probability using a trained Logistic Regression model.
  • Retrieves relevant guidance from sourced healthcare PDF documents.
  • Generates a patient-friendly care plan and a 7-day action calendar.

Important note

This tool is for educational support only. It does not diagnose stroke and does not replace advice from a qualified healthcare professional.
